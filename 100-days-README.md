## 📁 Ordnerstruktur

Jeder Tag-Ordner ist gleich aufgebaut:

```
day-001/
├── main.py       ← der eigentliche Code
└── notes.md      ← was ich heute gelernt habe
```

---

## 💡 Meine Lernregeln

1. **Jeden Tag committen** – auch wenn es nur 30 Minuten waren
2. **Code selbst tippen** – niemals copy-paste aus dem Kurs
3. **notes.md befüllen** – eigene Worte, nicht die des Lehrers
4. **Eigene Variante bauen** – nach jeder Lektion etwas abwandeln
5. **Nicht überspringen** – lieber langsamer als Lücken
